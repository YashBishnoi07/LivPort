# OIBSIP Web Development Task 1 - Personal Portfolio Website

## Objective
The objective of this task is to design and develop a responsive, interactive, and visually appealing personal portfolio website. This portfolio serves as a digital resume to showcase the developer's skills, academic background, projects, and achievements, offering a seamless user experience to potential recruiters and collaborators.

## Tools Used
*   **HTML5**: For structuring the content and semantic layout of the website.
*   **CSS3**: For advanced styling, responsive design, animations, and modern aesthetics (e.g., custom fonts, gradients, glassmorphism-like elements).
*   **JavaScript (Vanilla)**: For adding dynamic interactivity, such as a custom cursor, modal popups for project details, typing effects, and smooth scrolling.

## Steps Performed
1.  **Project Structuring**: Created the fundamental skeleton of the website including navigation, hero section, about, projects, tech stack, achievements, and contact sections.
2.  **UI/UX Design Implementation**: Applied a custom CSS theme using rich typography (Google Fonts like Space Mono, Caveat, Playfair Display), a dark aesthetic, and floating ambient text animations to create a hacker/developer vibe.
3.  **Component Development**:
    *   **Hero Section**: Added floating code snippets, an engaging tagline, and a clean call-to-action navigation.
    *   **Projects (The Bookshelf)**: Created a unique, interactive bookshelf UI where each project is represented as a clickable book that opens a detailed modal popup.
    *   **Tech Stack**: Structured a grid layout to categorize and display technical skills (Languages, Frontend, Backend, Tools).
4.  **Interactivity & Animations**: Integrated vanilla JavaScript to implement a custom cursor that reacts to hover states, dynamic modal dialogs for the projects, and smooth scrolling for navigation links.
5.  **Responsiveness & Polish**: Ensured the layout adapts elegantly to different screen sizes (mobile, tablet, and desktop) and optimized the overall performance.

## Outcome
The final outcome is a fully functional, highly interactive, and uniquely designed personal portfolio website. It successfully highlights the developer's proficiency in full-stack development (MERN, Flask), Data Structures & Algorithms, and AI/ML, packaged in a premium and engaging user interface.
